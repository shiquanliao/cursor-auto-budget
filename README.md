# Cursor Auto Budget

一个免费、开源、纯本地运行的 **Cursor Auto 用量与免费额度计算器**。

它回答三个最实际的问题：

- 一笔免费额度，大约能完成多少次轻量 / 常规 / 深度任务？
- 每日签到到底能补充多少可用额度？
- 运营方给 100 位新用户发体验额度，预算上限是多少？

> 这是非官方社区工具，与 Cursor / Anysphere 无隶属或授权关系。

## 为什么做这个项目

“免费 20 次”“无限使用”看起来简单，但一次任务的上下文长度、输出长度和工具调用次数都不同，固定次数往往不准确。

这个项目把承诺改成可验证的三个数字：

1. 发放多少真实余额；
2. 按轻量 / 常规 / 深度任务分别估算次数；
3. 明确展示计算公式和运营成本上限。

## 推荐的首发免费体验

| 阶段 | 奖励 | 原始额度（500,000 = $1） | 目的 |
|---|---:|---:|---|
| 注册完成 | $0.50 | 250,000 | 让用户立即完成一次轻量体验 |
| 完成安装并首次连接 | $1.50 | 750,000 | 合计 $2，覆盖至少一次常规任务 |
| 每日签到 | $0.05–$0.15 | 25,000–75,000 | 保持回访，不把签到做成主收入 |
| 连续 7 天 | $0.50 | 250,000 | 奖励真实留存 |
| 有效邀请 | $0.50 | 250,000 | 被邀请人真实使用后才发放 |

不要直接承诺固定次数。建议在产品里写：

> 注册先得 $0.50，完成安装后合计 $2 免费体验额度。按近期真实用量估算，约可完成 1 次常规任务或 6 次轻量任务，实际消耗以任务长度为准。

完整的防刷、预算上限和系统落地方式见 [免费层设计](docs/FREE_TIER_DESIGN.md)。

## 本地运行

无需安装依赖：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 测试

```bash
npm test
```

## 安全边界

本项目不会也不计划提供：

- 批量注册或临时邮箱自动注册；
- 验证码 / Turnstile 绕过；
- 机器标识重置；
- 修改第三方订阅状态；
- 窃取或共享第三方账号凭据。

它只做预算估算和合规的自有平台体验额度设计。
